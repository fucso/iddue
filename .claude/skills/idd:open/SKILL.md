# `/idd:open` — Issue 起票エントリーポイント

IDD 開発フローのエントリーポイント。
説明からレベルを判定し、対応する `idd:open:{level}` スキルへ委譲する。

## 参照

- [`references/levels.md`](references/levels.md) — レベル定義・判定基準

## 使い方

```
# レベルを自動判定する（説明文から推定）
/idd:open
/idd:open ログイン後に500エラーになる

# レベルがわかっている場合は直接呼び出しも可能
/idd:open:{level}
```

---

## 実行内容

### Phase 1: 情報収集

引数に説明文が渡されている場合はそのまま使用する。
引数がない場合は「どんなことを起票したいですか？」と聞く。

1回の返答でレベルを判定できない場合は**追加の質問を繰り返して構わない**。
ユーザーから具体的な情報が引き出せるまで対話を続ける。

### Phase 2: レベルの判定

`references/levels.md` の判定基準に従ってレベルを決定し、ユーザーに確認する：

```
集まった情報から「具体的な改修（concrete）」と判定しました。
このまま進めますか？（変更する場合: concrete / bug / problem / idea）
```

### Phase 3: 対応スキルへの委譲

確定したレベルの `idd:open:{level}` スキルを実行する。
Phase 1〜2 で収集した情報をコンテキストとして渡し、情報収集の出発点にする。
